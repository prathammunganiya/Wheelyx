## Summary of Core Objectives
1. **Target User Personas:**
   - **Customer:** Seamless discovery, transparent checkout, GPS trip telemetry, and genuine feedback.
   - **Vehicle Owner:** Fleet listing, digital key dispatch with odometer readings, and earnings analytics.
   - **Platform Admin:** System health, maintenance grounding, user governance, and security audit logs.
2. **Geographic & Fleet Footprint:**
   - 20 Major Indian Cities with 10 authentic landmark hubs each (200 hubs).
   - 36 Real vehicle models spanning 6 categories (Cars, Bikes, Petrol Scooters, EV Scooters, EV Cars, Premium Vehicles).
3. **Core Engineering Standards:**
   - Layered MVC architecture using Jakarta Servlets 6.0 and MySQL 8.0.
   - Concurrency safety, parameterization against SQL injection, and BCrypt cryptography.
