# Design Images Directory

This directory stores visual system architecture diagrams, database entity-relationship schema visualizations, and exported UML diagram assets for Wheelyx:

- `architecture_overview.png`: High-level MVC architecture flow diagram
- `database_er_diagram.png`: Visual schema diagram of all 17 MySQL tables
- `use_case_diagram.png`: Multi-actor platform use-case visual
- `sequence_booking_flow.png`: Booking, checkout, and handover sequence diagram

*(Note: Raw diagram sources are maintained in `../mermaid_source/` in standard Mermaid format).*
